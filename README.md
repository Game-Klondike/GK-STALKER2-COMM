# Zone Companion — спільнота

Публічний репозиторій спільноти **Zone Companion** (S.T.A.L.K.E.R. 2 + «Ціна Надії»), частини проєкту
**Ігровий Клондайк / Game Klondike**. Сам застосунок закритий; тут — усе, що робимо разом:

- **Issues** — помилки в даних, баги застосунку, пропозиції, переклади. Найзручніше — кнопка
  «Повідомити про помилку» в самому застосунку: вона заповнює звіт технічним контекстом.
- **Куровані дані** (`curated/`) — пропускні моменти, поради, порядок проходження, з джерелами. Pull request вітаються.
- **Переклади** інтерфейсу.

Zone Companion — неофіційний фанатський проєкт, не пов'язаний з GSC Game World. S.T.A.L.K.E.R. 2, «Ціна Надії»,
назви, тексти й мапа гри належать GSC Game World.
